CARTE ITALIANE V2 - iPHONE OFFLINE WEB APP

UPLOAD / UPDATE ON GITHUB PAGES

1. Open your public GitHub Pages repository (e.g. my-html-apps).
2. Upload all 7 app files directly into the root folder, not inside a folder or ZIP.
   Files: index.html, style.css, app.js, manifest.json, service-worker.js,
          icon-192.png and icon-512.png.
3. Commit the changes. GitHub Pages publishes automatically when enabled.
4. Open https://YOUR-USERNAME.github.io/my-html-apps/ in Safari.
5. Refresh once after publishing, then use Share > Add to Home Screen.
6. Open the installed app while online once to cache it for offline use.

IMPORTANT
- Do not upload the ZIP itself. Extract it first.
- Existing prototype scores should import automatically from local storage if you
  open this in the same Safari / Home Screen app origin as before.
- Export a backup from Settings before deleting Safari website data.
- Scores are not synchronised across devices.

RULES
- Scopa: most cards, most Denari, Settebello, Primiera, Scopas, optional Napola.
- Briscola: tap your scoring cards, other player's points = 120 minus yours;
  winning a deal earns 1 match win, ties earn none. Open-ended matches.
- Gin Rummy: 10-point knock limit, 25-point gin/undercut, 31-point big gin;
  automatic undercut detection. Enter deadwood after allowed lay-offs.
